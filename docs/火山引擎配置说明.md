# 火山引擎（豆包大模型）配置说明

本文档说明如何在新电脑上配置 CloudCLI 接入火山引擎（豆包大模型）。

## 前置要求

1. 已安装 OpenCode CLI：`npm install -g @anthropic-ai/claude-code`
2. 已克隆并配置 CloudCLI 项目
3. 已获取火山引擎 API Key

## 配置步骤

### 1. 配置 OpenCode provider

创建 OpenCode 配置文件（如果不存在）：

**路径**：`C:\Users\<你的用户名>\.config\opencode\opencode.json`

**内容**：
```json
{
  "provider": {
    "volcengine": {
      "apiKey": "${VOLCENGINE_API_KEY}",
      "baseURL": "https://nd-sub2api.sdp.ndaeweb.com"
    }
  }
}
```

> 注意：`apiKey` 使用环境变量引用 `${VOLCENGINE_API_KEY}`，不要直接写明文密钥。

### 2. 配置 CloudCLI 环境变量

编辑 CloudCLI 项目根目录的 `.env` 文件：

**路径**：`D:\CommonProject\claudecodeui\.env`（或你的项目路径）

**添加以下配置**：
```ini
# 火山引擎（豆包大模型）
VOLCENGINE_API_KEY=你的火山引擎API密钥
VOLCENGINE_BASE_URL=https://nd-sub2api.sdp.ndaeweb.com
```

### 3. 重启 CloudCLI 服务

双击运行：`tools\更新并重启.bat`

或手动重启：
```powershell
# 停止现有服务
Stop-Process -Name node -Force -ErrorAction SilentlyContinue

# 启动服务（通过计划任务）
schtasks /run /tn CloudCLI
```

### 4. 验证配置

1. 打开浏览器访问 CloudCLI（通常是 `https://localhost:33001` 或配置的地址）
2. 在 provider 下拉列表中选择 **OpenCode**
3. 在模型列表中应该能看到火山引擎的可用模型（如 `doubao-pro-32k`）
4. 发送测试消息验证是否能正常调用

## 配置说明

### 工作原理

- CloudCLI 作为 Web 服务运行，读取 `.env` 文件中的环境变量
- CloudCLI 调用 OpenCode CLI 时，OpenCode 从 `~/.config/opencode/opencode.json` 读取 provider 配置
- OpenCode 将配置中的 `${VOLCENGINE_API_KEY}` 替换为实际的环境变量值
- 最终 OpenCode 使用配置的 `baseURL` 和 `apiKey` 调用火山引擎 API

### API Key 获取

从公司的火山引擎控制台获取：
- 火山引擎控制台 → API 管理 → 创建 API Key
- 或联系管理员获取

### 常见问题

**Q: 找不到火山引擎模型？**
- 检查 OpenCode 配置文件路径是否正确
- 确认 `.env` 文件中 `VOLCENGINE_API_KEY` 已正确配置
- 重启 CloudCLI 服务后刷新浏览器页面

**Q: 提示 "Unrecognized flag: --dir" 错误？**
- 确保 OpenCode CLI 是最新版本：`npm install -g @anthropic-ai/claude-code@latest`
- 确保 CloudCLI 代码已更新到最新版本（包含 OpenCode 兼容性修复）

**Q: API 调用失败？**
- 检查 API Key 是否有效且未过期
- 确认 `baseURL` 配置正确
- 查看 CloudCLI 日志确认具体错误信息
