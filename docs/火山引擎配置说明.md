# 火山引擎（豆包大模型）配置说明

CloudCLI 通过 OpenCode provider 接入火山引擎。

## 方式一：环境变量配置（推荐）

在 `D:\CommonProject\claudecodeui\.env` 文件中添加：

```ini
# 火山引擎 API Key
VOLCENGINE_API_KEY=你的火山引擎API密钥
```

## 方式二：OpenCode 配置文件

创建或编辑 `C:\Users\Administrator\.config\opencode\config.json`：

```json
{
  "provider": {
    "volcengine": {
      "baseURL": "https://nd-sub2api.sdp.ndaeweb.com",
      "apiKey": "${VOLCENGINE_API_KEY}"
    }
  }
}
```

然后在 `.env` 中添加 `VOLCENGINE_API_KEY=你的密钥`

## 方式三：OpenCode auth.json

在 `C:\Users\Administrator\.local\share\opencode\auth.json` 中添加：

```json
{
  "volcengine": {
    "apiKey": "你的火山引擎API密钥"
  }
}
```

---

## 配置完成后

1. 重启 CloudCLI 服务：双击 `tools\更新并重启.bat`
2. 在 CloudCLI 前端选择 OpenCode provider
3. 模型列表中会显示火山引擎的可用模型

## 获取 API Key

从你们公司的火山引擎控制台获取 API Key，通常在：
- 火山引擎控制台 → API 管理 → 创建 API Key
